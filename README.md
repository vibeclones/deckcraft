# deckcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [deckcraft](https://github.com/storytold/deckcraft), a PowerPoint-style presentation editor by ArtCraft. This repo only mirrors upstream release zips; the code is theirs.

- Latest: `/deckcraft/latest/`
- Specific version: `/deckcraft/v<version>/`
- Version list: `/deckcraft/versions.json`

Each version folder is the unmodified contents of upstream's `deckcraft-web-<version>.zip` release asset, including its license files. Upstream license: . A scheduled workflow mirrors new releases.
